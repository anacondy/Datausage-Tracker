How this tracker works

  • WinRT API — reads the same per-app counters Windows Settings uses.
  • Adapter statistics — reads per-interface byte counters from the OS network stack.
  • Delta computation — compares current adapter counters against stored baselines.
  • Reboot-safe — detects adapter counter resets and treats them as new usage (no double counting).
  • Low power — does not poll continuously; reads existing OS counters on demand.
  • Scheduled tracking — a Windows Task Scheduler entry runs every 30 minutes.
